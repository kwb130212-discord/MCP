세공 확률 전략실

세 항목의 공통 확률 흐름을 추적하고, 남은 기회를 계산해 선택을 도와줘.

현재 공통 성공 확률75%
최저 25% · 최고 75%
전체 세공 진행0 / 30성공 0 · 실패 0
3레벨 항목0 / 2목표: 1·2번에서 3레벨 확보

① 항목 선택 및 세공 기록

추천 분석
세공 결과를 기록하면 현재 확률과 남은 횟수를 바탕으로 다음 선택을 분석해.

성공/실패 버튼은 실제 게임 결과를 입력하는 용도야. 추천은 확률을 조작하거나 결과를 보장하지 않아.

② 항목별 목표

판정: 9~10승 = 3레벨, 7~8승 = 2레벨, 4~6승 = 1레벨, 0~3승 = 미달.

③ 세공 기록

아직 기록이 없어. 항목을 고르고 결과를 기록해 줘.

④ 확률 규칙

• 시작 확률 75%
• 성공하면 다음 세공 확률 -10%p
• 실패하면 다음 세공 확률 +10%p
• 확률은 25~75% 범위
• 세 항목이 같은 확률 공유
• 항목마다 세공 기회 10회

입력한 결과를 기준으로 추적해. 게임 내부 난수나 숨겨진 규칙을 읽을 수는 없어.
